# TWM Lab — human-facing station demo

Экспериментальная пользовательская оболочка для канонического neural runtime TWM.

Цель этого репозитория — сделать демонстрацию понятной человеку без технического контекста, **не меняя логику модели**. Предсказания, belief и recursive rollout по-прежнему считаются каноническими R12 weights по frozen R13 protocol.

## Принцип

**Нейросеть считает → адаптер переводит формат → UI показывает.**

UI не имеет права:
- исправлять prediction;
- подставлять скрытый закон;
- использовать recorded future для neural inference;
- заменять learned dynamics правилами;
- скрывать ошибки модели.

По умолчанию приложение открывается в режиме «Попробовать». Режимы «Как это работает» и «Технический» раскрывают больше деталей без изменения inference path.

Исходный проверенный runtime: https://github.com/codxqqq-lab/twm
